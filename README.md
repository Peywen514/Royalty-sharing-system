# 📈 線上課程版稅銷售與請款結算系統 (CSF Royalty Settlement System)

專為**線上課程版稅結算、平台對帳核對、發票請款申請單自動套印、講師分潤計算與 Google Sheets 線上雙表自動串聯**設計，結合會計審計邏輯與自動化架構。

---

## 🌟 核心功能

1. **雙向自動對帳與審計**：支援 104、PressPlay (PPA) 等多平台對帳單與經辦自填明細表精確核算（含稅/未稅金額、稅額、分潤成數、數量相符檢查）。
2. **自動生成標準 Word 請款單**：依據《附件1_發票收據申請單》標準格式自動套印，連動自填表日期推算隔月底入帳日。
3. **講師分潤與製作成本扣除**：自動計算各講師本期應付版稅並產出專屬明細 Excel 活頁簿。
4. **影印機連線與 A4 仿真預覽**：內建直接連接 Windows 實體事務機/影印機，一鍵開啟標準列印設定。
5. **本機檔案總管選取與瀏覽上傳**：自由點選桌面或電腦任意目錄下的 Excel 檔案。
6. **Google Sheets 雙表自動串聯**：支援平台對帳表與講師分潤表自動分流寫入線上試算表。

---

## 🚀 快速開始 (跨裝置部署與執行)

### 1. 安裝環境需求
- **作業系統**：Windows 10 / 11
- **Python 版本**：Python 3.10 以上

### 2. 安裝必要套件
在終端機中切換至專案資料夾並執行：
```bash
pip install -r requirements.txt
```

### 3. 啟動系統
- **方法一（最推薦）**：雙擊桌面捷徑 **`版稅銷售系統 (CSF)`** 或專案目錄下的 **`啟動版稅銷售系統.bat`**。
- **方法二**：於終端機執行：
  ```bash
  python server.py
  ```
- 系統將自動啟動本機伺服器並以瀏覽器開啟：`http://127.0.0.1:8990`。
